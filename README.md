# 复星保德信轻资产创业招募 Skill

> 基于「人生规划 × 销售潜质」双轨评估模型，帮助招募负责人与潜在代理人深度沟通的 AI 平台 Skill。
> 适配豆包、DeepSeek、元宝等主流 AI 助手平台。

## 在线体验

**🌐 网页版（推荐）**：https://20091229F.github.io/fox-recruitment-skill/
- 完整的 6+6 销售潜质自测（12题快速版 + 6题人生规划）
- 公司介绍、收入测算、培训体系、产品介绍
- 预约面试表单

**🤖 豆包智能体**：https://doubao.com/bot/7RusUxbb
- 对话式咨询，了解轻资产创业机会
- 引导至网页版完成自测
- 预约面试

## 核心设计

**轻资产创业 = 自己当老板 + 时间自主 + 收入无上限**

- 12 维度评估模型（收入/成就感/公平性/人际/未来发展/企业理念/学习成长/家庭/兴趣/子女教育/社会贡献/梦想）
- 不是对工作的不满，而是对未来的梦想与目标的不安与不满
- 对话从「人生规划」切入，而非「岗位介绍」

### 导入 AI 平台
将 `recruitment.skill` 文件内容复制到豆包/DeepSeek/元宝的智能体设定中：
- **豆包**：创建智能体 → 粘贴提示词 → 发布
- **DeepSeek**：创建智能体 → 设置角色指令 → 发布
- **元宝**：创建智能体 → 配置提示词 → 发布

触发词：
- "你好" / "开始" / "招募" / "创业"
- "轻资产" / "保险" / "代理"
- "测试" / "自测" / "收入" / "培训"
- "预约" / "面试"

## 合规要求

本 Skill 严格遵守保险行业合规要求：
- 2026.05 更新：移除展业话术中的历史投资收益率
- 所有收入表述必须标注"以基本法为准，非承诺"
- 产品利益演示需注明"以合同条款为准"
- 不使用"保证""肯定""绝对"等确定性词汇描述收益
- NPS 等满意度指标客观表述，不夸大
