# 产品体系简介

> 供候选人与客户沟通时参考，了解公司产品竞争力。
> ⚠️ 具体产品责任、费率、红利分配以保险合同为准。

## 一、产品线概览

复星保德信的产品策略：**功能破局 + 生态赋能**
不是单纯比拼收益，而是打造"产品 + 服务"的综合解决方案。

```
主力产品体系
  ├── 终身寿险（分红型）→ 财富传承、资产保值
  ├── 养老年金（分红型）→ 养老规划、终身现金流
  ├── 重大疾病保险     → 健康保障、家庭守护
  └── 意外伤害保险     → 出行保障、高杠杆
```

## 二、明星产品详解

### 星福家朱雀版A 终身寿险（分红型）

**定位**：财富传承 + 资产保值增值

**产品特色**：
- 英式保额分红（增额红利 + 终了红利双重分配）
- 红利分配方式更先进，长期表现可期
- 基本保险金额可变更（在合同约定条件下），提供流动性与灵活性
- 定价遵循现行监管要求，贴近长期规划需求

**适合人群**：
- 想做财富传承的高净值客户
- 希望资产配置更多元化的中产家庭
- 寻求稳健增值 + 保障兼顾的人群

**展业卖点**：
"不是单纯一个理财产品，而是一份'确定的承诺'——保额递增 + 红利分配，两个维度都照顾到。"

---

### 星福家玄武版A 终身寿险（分红型）

**定位**：更灵活的终身寿险选择

**产品特色**：
- 多种缴费期选择（1年/3年/5年/6年/7年/10年）
- 首年佣金率最高26%（10年交）
- 适合不同资金规划需求的客户

**适合人群**：
- 希望短期缴清、长期持有的人群
- 税务规划需求的中高产客户

---

### 星海赢家传世版 养老年金保险（分红型）

**定位**：早期领取 + 终身现金流

**产品特色**：
- **三形态切换**：早期领取型年金 / 阶段领取型（教育金、养老金）/ 终身保额递增型寿险
- **最快次年领**：首个保单周年日即可申请领取第一笔现金红利（以合同约定为准）
- **领取稳**：合同约定的年金领取 + 红利分配，长期规划价值持续
- **好传承**：身故保险金（基本 + 红利两部分），财富有序传承
- **规划灵**：符合条件可变更基本保险金额
- **承保宽**：没有健康告知和体况要求，1-7类职业可承保

**适合人群**：
- 30-45岁，正在做养老储备的人群
- 希望"最快次年就有现金流"的客户
- 身体有异常、其他保险买不了的人群

**展业卖点**：
"市面上大多数年金要等5年、10年才能领，这款最早**次年就能领**——现金流规划更灵活。（具体以合同条款为准）"

---

### 星无忧2026 重大疾病保险

**定位**：全面健康保障

**产品特色**：
- 覆盖重疾、轻症、中症多重保障
- 多种缴费期选择（5年/10年/18年/20年/30年）
- 首年佣金率最高30%
- 可与生态服务（就医绿通、二次诊疗）组合

**适合人群**：
- 有家庭责任（房贷、子女教育）的成年人
- 希望"保障 + 服务"一体化的客户

---

### 出行保（庆典版）/ 团体驾乘人员意外险

**定位**：高杠杆意外保障

**产品特色**：
- 首年佣金率10-15%
- 适合作为"第一份保险"或"加保"工具
- 团体险可覆盖家庭多个成员

**展业卖点**：
"意外险是保险入门的首选——保费低、保障高，客户容易做决策。"

## 三、产品竞争力总结

| 维度 | 复保产品优势 | 展业话术角度 |
|---|---|---|
| 分红形态 | 英式保额分红，双红利设计 | "不是只有一种分红方式，而是两种红利都参与分配" |
| 领取灵活性 | 星海赢家最早次年领 | "别的年金要等5年，这款次年就能领" |
| 承保宽松度 | 无健康告知，1-7类职业 | "身体有异常也能买，这是很大的优势" |
| 生态绑定 | 五大生态体系，产品即服务 | "买保险不是结束，是享受服务的开始" |
| 佣金竞争力 | 长险首年佣金率最高30% | "好产品自己会说话，你只需要做专业的翻译官" |

```
"你目前最担心的风险是什么？
  → 养老 → 推星海赢家
  → 财富传承 → 推星福家朱雀版
```
