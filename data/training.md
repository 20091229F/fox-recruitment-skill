# 培训体系说明

> 复星保德信的培训理念：**不是"丢给你自生自灭"，而是"平台赋能 + 自主经营"**

## 一、培训进阶路径

```
新人入职
  ↓
新人培训班（岗前培训）
  ↓
试用期辅导（主管1对1带教）
  ↓
转正培训
  ↓
各级晋升培训（BM → SBM → EBM → BD）
  ↓
绩优培训（桂林培训等高阶研修）
  ↓
持续教育（法规、产品、生态服务持续更新）
```

## 二、各阶段培训内容

### 新人培训班（岗前）

- **保险基础知识**：保险法、产品类型、投保流程
- **合规底线**：销售行为合规、客户信息保护、禁止误导销售
- **基础话术**：需求激发、方案呈现、异议处理
- **系统操作**：投保系统、客户管理工具使用

### 试用期辅导（1对1带教）

- 主管陪同展业（前3单）
- 每周1次复盘会
- 主管负责解答实操问题

### 转正后持续培训

| 培训类型 | 频率 | 内容 |
|---|---|---|
| 晨会/夕会 | 每周1-2次 | 产品更新、话术演练 |
| 月度经营分析 | 每月 | 个人业绩复盘、下月目标设定 |
| 季度进修班 | 每季度 | 法规更新、高阶销售技巧 |
| 年度表彰/进修 | 每年 | 绩优人员国内外进修机会 |

## 三、"准独代"模式优势

### 与传统公司对比

| | 传统金字塔模式 | 复保准独代 |
|---|---|---|
| 管理方式 | 早会打卡、强管理 | 自主经营、结果导向 |
| 培训重心 | 话术背诵 | 专业能力 + 生态工具使用 |
| 主管角色 | 管理者 | 教练 + 合作伙伴 |
| 收入结构 | 依赖层级抽成 | 个人业绩为主 + 团队津贴 |

### 平台赋能（ NOT "放养"）

- **产品支持**：25年持续推出竞争力产品（星福家、星海赢家等）
- **生态工具**：五大生态体系（后详）提供差异化服务工具
- **内勤支持**：核保、理赔、保全等专业支持
- **科技工具**：投保系统、客户管理CRM、线上培训平台

## 四、五大生态体系（培训重点内容）

培训中会用大量时间让代理人**熟练使用生态工具**，因为这是展业的核心差异化优势。

### 星守护（健康管理）

- 高端体检安排
- 就医绿通（三甲医院挂号、住院协调）
- 二次诊疗意见

### 星启航（教育规划）

- 藤校规划咨询
- 就业护航服务
- 教育金规划工具

### 星享寿（养老规划）

- 居家照护服务
- 康养旅居（复星文旅资源）
- 养老社区对接

### 星富足（财富规划）

- 法税咨询服务
- 投资讲座（复星资管视角）
- 财富传承规划工具

### 星快乐（品质生活）

- 复星文旅体验（地中海俱乐部等）
- 家庭活动策划
- 高端客户圈层活动

## 五、培训资源投入

- 2025年开展生态活动 **1,100+ 场**，覆盖 **4.3万 客户**
- 培训讲师团队：内勤专业讲师 + 外聘行业专家
- 培训费用：公司承担，代理人无需自费

## 六、成长案例（培训后效果）

> 以下为行业通用成长路径描述，非特定个人案例

**第1年**：完成新人培训 → 转正 → 月均FYC 5,000-15,000元
> 参考：按首年佣金率约10%-20%计算，月均FYC 5,000-15,000元对应月签单约1-3件
**第2-3年**：晋升高级合伙人 → 开始带团队 → 月收入15,000-30,000元
**第4-5年**：晋升业务经理 → 天狼星方案受益人 → 月收入30,000元+
