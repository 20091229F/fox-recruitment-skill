# 复星保德信代理人招募助手 Skill

> 一个帮助候选人通过对话了解「保险代理人」作为轻资产创业项目的 Skill。
> 不是"招人上班"，而是"邀你共建一份自主的事业"。

## 核心理念

**保险代理 = 轻资产创业，不是一份工作**

- 启动成本极低（不需要租房、进货、雇人）
- 收入上限由专业能力决定（多劳多得，上不封顶）
- 客户关系是自己的资产（做越久，资源越丰厚）
- 时间自主，兼顾家庭与工作

## 对话流程

```
用户进入
  │
  ├─→ 6+6 人生规划对话（questionnaire/6+6.md）
  │   前6问：关于现状
  │   后6问：关于未来
  │
  ├─→ 适配度判断（高适配 → 继续；低适配 → 诚实告知）
  │
  ├─→ 公司介绍（data/company.md）
  ├─→ 薪资测算（data/commission.md）
  ├─→ 培训体系（data/training.md）
  │
  └─→ 预约面试（收集信息 → 发送邮件）
```

## 安装方式

### 方式一：WorkBuddy 用户级安装

将本仓库 clone 到 `~/.workbuddy/skills/`：

```bash
cd ~/.workbuddy/skills/
git clone https://github.com/[你的用户名]/fox-protector-recruitment-skill.git
```

重启 WorkBuddy，Skill 自动生效。

### 方式二：项目级安装

将本仓库复制到项目根目录的 `.workbuddy/skills/`：

```bash
cd /你的项目路径/
mkdir -p .workbuddy/skills/
cp -r fox-protector-recruitment-skill .workbuddy/skills/
```

## 使用方式

安装后，在 WorkBuddy 中对我说：

- "保险代理人招募"
- "我想了解复星保德信"
