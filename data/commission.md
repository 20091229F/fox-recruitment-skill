# 佣金与收入测算

> 本文件提供复星保德信代理人佣金结构详细规则，供薪资测算使用。
> ⚠️ 所有测算结果仅为示例参考，不构成任何收入承诺。

## 一、收入构成

```
代理人月收入 =
  个人业务佣金（FYC × 佣金率）
  + 绝对双佣补足
  + 续年度佣金（RYC）
  +（如有）天狼星组织津贴
  + 各类竞赛奖金
  − 税金（代扣代缴）
```

## 三、绝对双佣机制

**核心逻辑**：当FYC达到特定阈值或处于档位过渡区间时，通过政策追加佣金，确保绩优者获得与贡献匹配的回报。

### 责任津贴档位（入司首年）

| 当月FYC（元） | 责任津贴（元） |
|---|---|
| 4,000 ≤ FYC < 10,000 | 4,000 |
| 10,000 ≤ FYC < 30,000 | 10,000 |
| 30,000 ≤ FYC < 80,000 | 30,000 |
| FYC ≥ 80,000 | FYC × 40% |

### 入司第二年起

| 当月FYC（元） | 责任津贴（元） |
|---|---|
| 4,000 ≤ FYC < 10,000 | 4,000 |
| 10,000 ≤ FYC < 30,000 | 10,000 |
| 30,000 ≤ FYC < 80,000 | 30,000 |
| FYC ≥ 80,000 | FYC × 40% |

### 绝对双佣追加示例

| 当月FYC（元） | 责任津贴（元） | 绝对双佣追加（元） | 合计（元） |
|---|---|---|---|
| 5,000 | 4,000 | 1,000 | 10,000 |
| 80,000 | 32,000 | 48,000 | 160,000 |

**机制说明**：
- 基本法责任津贴保障底线
- 绝对双佣政策打开上限
- 绩优者始终处于激励曲线上升区间
- 所有长险产品均适用绝对双佣

## 五、收入测算示例

> ⚠️ 以下仅为示例参考，非承诺收入，以基本法规定为准

### 场景一：兼职起步（月均FYC约5,000元）

- 每周投入2-3天，月均签单1-2件
- 参考产品：星海赢家传世版（5年交），首年佣金率9.5%
- 月均FYC 5,000元 → 责任津贴4,000元 + 绝对双佣追加1,000元
- **月收入参考**：约2,000-4,000元（仅供参考）

### 场景二：全职常规（月均FYC约15,000元）

- 每周投入5天，月均签单3-5件
- 参考产品：星福家朱雀版A（10年交），首年佣金率20%
- 月均FYC 15,000元 → 责任津贴10,000元 + 绝对双佣补足
- **月收入参考**：约6,000-12,000元（仅供参考）

### 场景三：绩优发展（月均FYC约40,000元）

- 全职+有团队，个人+组员业绩
- 月均FYC约40,000元 → 责任津贴16,000元 + 绝对双佣追加16,000元
- 如有直辖组标保≥30万，额外天狼星津贴约4,000元
- **月收入参考**：约40,000元（仅供参考，以基本法为准）

## 六、收入发放规则

- **发放日**：每月28日（遇节假日以公司通知为准）
- **到手金额**：税前，应纳税金由公司代扣代缴
- **佣金条件**：需完成客户亲笔签署并核销保单回执、保单过犹豫期且通过回访
- **离职/关号**：仅核发当月直接佣金和竞赛方案，次月起不再发放各项收入
